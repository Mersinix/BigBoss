BigBossCoffee – Add the New Maintenance Service
Mission

Add a new Maintenance service to the BigBossCoffee ecosystem by following exactly the same UX, UI philosophy, navigation, permissions, responsiveness, and quality level as the existing services (Shop / Print / Barista / Marketing).

IMPORTANT RULES (NON-NEGOTIABLE)

Before making any modification:

Analyze the entire project architecture.
Understand how the existing services (Shop, Print, Marketing, Barista) are connected.
Identify every place where services are synchronized.
Verify all shared components, permissions, navigation, favorites, chat, routing, translations, responsive layouts, APIs, database models, and reusable UI.
Make sure every new Maintenance feature follows the existing project architecture.
Before writing any code

Perform a complete impact analysis and verify that every dependency related to marketplace services is identified before making any modification.

Only after verifying the synchronization points should implementation begin.

Do NOT
change existing business logic.
refactor unrelated code.
modify existing designs.
remove existing features.
rename existing components.
change existing routes.
modify existing APIs unless strictly required for Maintenance.
break synchronization between services.
affect Shop, Print, Marketing, Barista, Suppliers, Delivery, Admin, or Coffee Owner modules.

Only add what is necessary for the new Maintenance service.

Everything unrelated to Maintenance must remain exactly as it is.

If an existing component does not require modification, leave it untouched.

NEW SERVICE

Create a new marketplace service:

Maintenance

This service connects Coffee Owners with maintenance professionals capable of repairing, installing and maintaining any equipment or infrastructure used inside coffee shops.

The service must integrate naturally into the existing BigBossCoffee ecosystem exactly like the other marketplace services.
