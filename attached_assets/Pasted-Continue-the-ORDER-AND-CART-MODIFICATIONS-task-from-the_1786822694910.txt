### ADDITIONAL REQUIREMENT — ORDER PROGRESS PER SUB-ORDER

There is one important correction to the previous Order/Cart task.

A single Coffee Owner order can contain products/Packs from **multiple suppliers**, therefore it can contain multiple **SubOrders**, and each SubOrder can have its own status.

For example:

* **Ooredoo** → En attente
* **Café Bondin** → En préparation

Currently the Order Details view displays only one global **Order Progress**, which is incorrect for multi-supplier orders.

### Required behavior

Inside **My Account → Orders → Order Details**, the **Order Progress must be displayed separately for EACH SubOrder / Supplier**.

For every supplier section, show:

**Supplier name**

**Current status**

**Order Progress**

**Order Placed → Confirmed → Preparing → Ready for Delivery → Out for Delivery → Delivered**

The progress indicator must reflect the **actual status of that specific SubOrder**.

For example:

**Ooredoo**

* Status: En attente
* Order Progress:

  * Order Placed ← current stage
  * Confirmed
  * Preparing
  * Ready for Delivery
  * Out for Delivery
  * Delivered

**Café Bondin**

* Status: En préparation
* Order Progress:

  * Order Placed
  * Confirmed
  * Preparing ← current stage
  * Ready for Delivery
  * Out for Delivery
  * Delivered

Do NOT show one global progress indicator for the entire order when multiple suppliers/sub-orders have different statuses.

The Coffee Owner must be able to clearly understand the progress of **each supplier's part of the order independently**.

This must remain synchronized with the actual SubOrder status updates in realtime.

Do not change the existing order status logic. Simply make the existing progress display correctly represent each SubOrder.

Keep the existing design and order-detail structure. Only adjust the progress placement/behavior necessary for this requirement.

Also make sure this works for:

* One supplier → one SubOrder
* Multiple suppliers → multiple SubOrders
* Different statuses between suppliers
* Status changes after the order was created
* Realtime status updates
* Existing Cancel / Reorder / Close actions
