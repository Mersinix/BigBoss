# 3. Supplier rejection behavior

If the Supplier rejects:

* the full order
  or
* part of the order belonging to that Supplier

then the rejected items must return to the Coffee Owner cart.

The Coffee Owner should be able to reorder those items from another supplier.

Do not lose the items.

Keep:

* Product information
* Variant
* Flavor
* Size
* Quantity

when returning items to cart.

---

# 4. Coffee Owner cancellation and stock restoration

If the Coffee Owner cancels an order:

Only if stock was already deducted:

restore the exact stock.

The restoration must happen at:

* Product level
* Variant level
* Flavor level
* Size level

Example:

Original deduction:

```
FANTA 25cl
Variant: Gajou
Flavor: BLANC
Quantity deducted: 3
```

After cancellation:

```
BLANC stock +3
```

Do not restore:

* another flavor
* another variant
* total product stock only

Restore the exact inventory source.
