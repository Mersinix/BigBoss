# Coffee Owner → Store Page

A Store belongs to a single supplier.

Once the Coffee Owner enters a Store, everything displayed on that page must represent **only that supplier**.

The supplier comparison logic must remain available only in the Shop marketplace, not inside an individual Store.

---

# 1. Display Only This Store's Products

Currently, the Store page displays products as if they were marketplace products, showing multiple suppliers for the same product.

This should be changed.

Inside a Store:

* Display only the products that belong to the supplier who owns that Store.
* Do not compare products with other suppliers.
* Do not merge listings from different suppliers.
* Do not show marketplace-style product aggregation.

The Shop page should continue to work exactly as it does today.

Only the Store page should change.
