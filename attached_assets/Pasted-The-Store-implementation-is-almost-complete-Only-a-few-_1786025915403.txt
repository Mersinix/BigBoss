# 1. Store Product Card Pricing

Currently, when a product has a promotion, the Product Card inside the Store displays the old price twice.

This is incorrect.

The Product Card should display:

* The discounted price (after applying the promotion) as the main price.
* The original price below (or beside it, according to the existing design) with a strikethrough.

Also ensure that every price uses the project's global currency format, with the currency symbol displayed on the **right side** of the value (matching the current currency strategy used throughout the project).

When opening a product from inside a Store:

If the product has a promotion:

* Display the discounted price as the main price.
* Display the original price with a strikethrough.
* Do not display the original price as the active price.

Also remove the text:

**"Starting from"**
