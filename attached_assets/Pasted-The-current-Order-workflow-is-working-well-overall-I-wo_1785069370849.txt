Verify that:

changing an Order status from the Supplier side immediately updates:
Coffee Owner
Admin

Order Requests Synchronization

Order Requests
→ confirmation
→ Orders

Coffee Owner
Admin

If the Supplier changes an Order status inside the Orders tab back to "En attente" (Pending),
