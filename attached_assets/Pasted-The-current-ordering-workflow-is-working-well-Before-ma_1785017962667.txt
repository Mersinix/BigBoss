1. Coffee Owner → Cart → Order Confirmation

The current cart works correctly.

Before the order is submitted, add one additional confirmation step.

When the Coffee Owner clicks "Passer commande", do not immediately create the order.

Instead, open a "Récapitulatif" (Order Summary) confirmation modal.

The modal should allow the Coffee Owner to:

review the complete order
review every supplier section
review Packs and Products
review delivery address
review delivery instructions
review totals
review shipping information
confirm the order

Inside this modal the Coffee Owner should also be able to:

remove individual products
remove Packs
adjust quantities where applicable
close/cancel the confirmation without creating the order

Only after clicking the final confirmation button should the Order actually be created.

The existing cart behavior should remain unchanged outside of this additional confirmation step.

4. Delivery Synchronization

Since one Order may contain multiple Suppliers,

the Delivery workflow must also stay synchronized.

The system should support multiple deliveries for one Order whenever necessary.

Each Delivery should correspond to the correct SubOrder.

Each Supplier should only see:

their own SubOrder
their own Products
their own Packs
their own customer instructions
their own delivery status

They must never see another supplier's items.

Delivery users should receive only the SubOrders assigned to them.

All statuses should stay synchronized in real time.

8. Duplicate Order Protection

Prevent accidental duplicate submissions.

The Coffee Owner must never be able to create the exact same order twice by mistake because of:

double-clicking
multiple taps
page latency
slow network
refreshes

The order submission flow should include appropriate safeguards so that only one order is created for a single confirmation action.

The user should always receive clear feedback about the order status.
